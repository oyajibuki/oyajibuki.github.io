キャラ変翻訳機

かたいビジネス語を、好きなキャラに全自動翻訳

⏳ ただいまApp Storeに審査申請中です

「アジェンダ」「コンセンサス」「シナジー」……。かたいビジネス語の文章を貼るか話すだけで、 ギャル語や武士語、大阪弁などの好きなキャラの言い回しに全自動で翻訳するアプリです。

💬 通信も送信も一切ありません。 変換は端末内の辞書だけで行われ、入力した文章がどこかに送られることはありません。

8種類のキャラに変換

ギャル語 / ヤンキー語 / 小学生語尾や言い回しをまるごと入れ替えて、砕けたテンションに変換します。
武士 / 大阪弁 / 京都弁 / 博多弁 / 東北弁「ござる」「やんか」「どすなぁ」など、方言・キャラ語尾の特徴を再現します。

主な機能

  • ✍️
    貼るだけで全自動翻訳本文を入力欄に貼るか打つだけで、選んだキャラの言い回しにその場で変換されます。
  • 🎙
    音声入力にも対応マイクボタンを押して話すだけでも入力できます。最大20秒、開始・終了は振動と音で分かります。
  • 🔄
    Before/Afterをその場で比較元の文章と変換後の文章を並べて表示。キャラを切り替えて何度でも見比べられます。
  • 📤
    比較画像をそのままシェアBefore/Afterを1枚の画像として書き出し、SNSにそのまま投稿できます。
  • 🔒
    アカウント不要・通信なし登録は不要です。変換処理はすべて端末内で完結し、外部に送信されることはありません。
